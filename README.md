# DNA_Sequence_Analyzer
A beginner-friendly Python project for performing basic analysis of DNA sequences. No external Python libraries used.

FEATURES
● Calculate DNA sequence length
● Count individual nucleotides (A, T, G, C)
● Calculate nucleotide frequencies
● Calculate GC and AT content
● Generate the complementary DNA sequence
● Generate the reverse sequence
● Generate the reverse complement
● Transcribe DNA into mRNA
● Translate DNA into amino acid sequences
● Detect Open Reading Frames (ORFs)
● Search for user-defined motifs
● Basic input validation

Technologies Used
● Python
● Git & GitHub

How to Run
● Clone or download this repository.
● Open the project in a Python-supported environment.
● Run the Python file.
● Enter a DNA sequence when prompted.
